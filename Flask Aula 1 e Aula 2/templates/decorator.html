O que é um Decorator em Python?

Um decorator é uma função que envolve outra função para adicionar comportamentos extras sem modificar seu código original.

Para que serve?

Serve para reutilizar lógica comum entre funções, como autenticação, logs e controle de rotas.

Como o Flask usa decorators?

O Flask usa @app.route para associar uma URL a uma função Python:

@app.route("/decorator")
def decorator():
    return "Esta função responde à rota /decorator"
